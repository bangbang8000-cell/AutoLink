## 技能: 示例文件解析（示例 → 模板/项目）

当用户上传示例文件（Excel / JSON / CSV / 文本）并要求"按此示例生成配置/模板/项目"时，按以下步骤执行：

1. 从用户消息的附件列表读取文件路径，调用 `parse_file` 工具（参数：`path`=附件路径，可选 `type`）。
2. 根据 `result.parsed` 结构理解内容：
   - `kind=excel/csv`：`sheets[].rows` 为表格行（列名 → 值），看是否有规模/设备/机柜清单列；
   - `kind=project-config`：`data` 已是 ProjectConfig，可直接展示或沿用；
   - `kind=json/text`：`data`/`content` 为原始内容，提炼规模/协议/速率等要素。
3. 从解析结果提炼需求要素（服务器数量、协议、速率、存储、机柜约束），必要时调用 `generate_project` 生成规范化配置预览。
4. 用自然语言汇报：解析到的表结构/行数、提炼的关键要素、与示例的差异（缺失字段为默认推导），并输出 `📋 项目配置预览` + `project-config` 块（若已生成）。

注意事项：`parse_file` 为只读解析（AUTO）；大文件已截断（每 sheet 前 50 行、文本前 6000 字符），如内容不完整请告知用户补充。
