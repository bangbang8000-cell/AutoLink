## 一、背景与定位

### 1.1 问题背景

v2.8.X 交付了文件加载、拓扑持久化与交互增强，但**机柜规划与上架逻辑仍停留在"简单轮转"阶段**，与真实机房上架规则严重脱节：

- 128 台 DGX H100（单台 10.2KW、8U）在 42U 机柜下被分配到 **21 台/柜**，单柜功率高达 214KW —— 现实为 12/16KW 机柜仅能容纳 **1 台** GPU 服务器；
- 网络设备、通算、存储设备实际可多台共柜，但当前与 GPU 服务器使用同一分配逻辑；
- 交换机（参数网/存储网/带外/业务网）**完全不分配机柜**，拓扑连线机柜字段为空，机柜汇总与功率密度估算均缺失交换机；
- 前端机柜可视化（机架 Tab / 机房平面 / 功率热力）数据源全部依赖后端错误的机柜分配，错误被逐级传导。

### 1.2 产品定位

v2.9.X 定位为**物理规划能力补强版本**：让"机柜评估、上架分配、功率密度、报告输出"从**数量正确**升级为**物理合理**，成为可直接指导机房交付的规划工具。

### 1.3 v2.9.X 演进目标

| 维度 | 目标 | 关键举措 |
|------|------|----------|
| **更现实** | 机柜分配贴近物理约束 | 功率 + U 位双约束装箱，GPU 高功率独占机柜 |
| **更完整** | 全部设备参与上架 | 交换机/网络设备机柜分配，机柜汇总含交换机 |
| **更专业** | 机柜配置可调可控 | 散热方式、功率预设、独占策略、机柜清单报告 |
| **更一致** | 前后端分配统一 | 前端机柜数据源改用后端新算法，修复假数据回退 |
| **更智能** | 自动化分组 | 智能机柜分组（同类聚柜）、Scale-Up 域机柜分配 |

## 三、机柜分配算法设计（核心）

### 3.1 分配原则

```
输入: 设备列表 [{obj_type, group, power_watts, u_height}] + 机柜配置 {rack_type, power_limit_per_rack, cooling_method, gpu_dedicated}
输出: 每设备 {cabinet_id, cabinet_name, start_u, end_u} + 每柜 {type, total_power, device_count, percent, exceeded}
```

1. **功率约束优先**：任一柜内设备总功率 ≤ `power_limit_per_rack`；
2. **U 位约束次优**：已用 U + `u_height` ≤ `rack_type`；
3. **类型约束**：
   - GPU 服务器（功率 ≥ `power_limit × 0.5`）→ **独占机柜（1 台/柜）**，自然覆盖 H100/H200 场景；
   - GPU 服务器（功率 < `power_limit × 0.5`）→ 功率装箱（如 3.8KW MLU590 在 12KW 柜 → 3 台）；
   - 通算/存储服务器 → 功率 + U 位联合装箱；
   - 网络设备（param/storage/oob/biz 交换机）→ **按网段聚柜**（网络柜），功率 + U 位装箱；
4. **gpu_dedicated 开关**：开启时 GPU 服务器无条件 1 台/柜（硬约束）；关闭时按功率自然装箱。

### 3.2 现实对标（验收基准）

| 设备 | 功率/U | 12KW 柜 | 16KW 柜 |
|------|--------|---------|---------|
| DGX H100 (8×H100) | 10.2KW / 8U | **1 台** | **1 台** |
| HGX H200 (8×H200) | 12.0KW / 8U | **1 台** | **1 台** |
| Atlas 800T A2 (910C) | 6.5KW / 8U | 1 台 | 2 台 |
| MLU590 8 卡 | 3.8KW / 4U | 3 台 | 4 台 |
| 通算 2U-Compute | 0.8KW / 2U | 15 台 | 20 台 |
| 存储 All-Flash | 0.8KW / 2U | 15 台 | 20 台 |
| 参数 Leaf 64P-400G | 0.2KW / 1U | 42 台（U 位约束） | 42 台 |
| 51.2T CPO 交换机 | 3.5KW / 4U | 3 台 | 4 台 |

> 注：通算 12KW 柜 0.8KW×15=12KW、U 位 30U 均达标；16KW 柜 0.8KW×20=16KW、U 位 40U 达标。交换机 42 台受 U 位约束（42×1U=42U）。
