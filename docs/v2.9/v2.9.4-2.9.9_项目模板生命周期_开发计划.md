### 手测清单（模板全流程）
- [ ] 内置模板右键 → 基于此模板创建项目 → 向导预填 → 创建 → DesignTab 完整
- [ ] 用户模板（另存为模板）→ 同样流程
- [ ] 模板可视化编辑（规模/选型/机柜）→ JSON+INI 同步
- [ ] 模板预览（摘要 + 无落盘残留）
- [ ] 模板导入（含/不含 JSON）/导出 → 数据完整
- [ ] 损坏模板：创建/预览/健康检查均明确报错，不静默

### 兼容性
- 旧模板（仅 INI）：`project:create`/导入/预览不静默失败（自动生成或明确提示）
- 旧项目：不受模板改造影响，`project_config.json` 新增字段带默认值

## 九、依赖与风险

| 依赖/风险 | 说明 | 缓解 |
|-----------|------|------|
| ci.yml 推送需 workflow scope | 历史遗留（OAuth token 缺 workflow 权限） | v2.9.8 通过 GitHub connector 或手动提交 |
| 自动选型校准工作量 | 16 模板 device_refs 需人工核对 | 脚本生成默认 + 逐模板核对清单（PRD 附录 B 参考设备） |
| INI↔JSON 往返字段丢失 | 字段映射不全 | `project_config_to_ini` 全字段映射 + 往返一致性测试 |
| 向导预填破坏既有流程 | 预填覆盖用户输入 | 可重置为默认 + vitest 覆盖 |
