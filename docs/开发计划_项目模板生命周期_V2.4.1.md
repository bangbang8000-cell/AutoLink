## 4. 风险矩阵

| 风险 | 等级 | 缓解方案 |
|------|------|---------|
| archiver/adm-zip 兼容性 | 低 | 两个库均为成熟开源库，Electron 28 兼容 |
| ZIP 路径遍历攻击 | 中 | 严格校验解压路径，禁止 `..` 和绝对路径 |
| 大项目导出阻塞 UI | 中 | 异步操作 + 进度条 |
| 内置模板误编辑 | 低 | isBuiltin 标记 + UI 禁用 |
| 名称冲突处理 | 低 | 自动追加 `_副本`/`_导入` 后缀 |
| i18n 翻译遗漏 | 低 | 集中在 Phase J6 统一补全 |

## 6. 技术选型决策

### 6.1 ZIP 库选择
- **打包**：`archiver`（流式 API，性能好，社区活跃）
- **解压**：`adm-zip`（同步 API，简单易用，支持中文文件名）

### 6.2 文件操作
- 使用 Node.js `fs.cpSync`（Node 16.7+）实现递归复制
- 使用 `fs.renameSync` 实现重命名

### 6.3 安全校验
- 复用 `sanitizeName` 函数校验项目/模板名称
- ZIP 解压前遍历 entry，检测 `..` 和绝对路径
