## 7. 发版流程

### v2.6.0 发版
1. 更新 package.json version 为 2.6.0
2. 提交:`git commit -m "release: v2.6.0 紧急缺陷修复 [skip ci]"`
3. 打 tag:`git tag v2.6.0`
4. 推送 tag,手动 `gh workflow run build.yml --ref v2.6.0`
5. CI 三平台构建,验证 GitHub Release
