## 风险控制

| 风险 | 缓解 |
|------|------|
| T2/T3/T4 全局替换遗漏 | 使用 `grep` 搜索 `dark:bg-gray-900`/`dark:bg-gray-800`/`dark:border-gray-700` 确认无遗漏 |
| Modal 背景色替换后内容区不可见 | Modal 使用 `bg-surface` 而非 `bg-elevated`,确保与内容区有区分 |
| 动画 `animate-in` 在 Tailwind v3 中可能不可用 | `animate-in` 是 `tailwindcss-animate` 插件提供的,需确认项目是否已安装;若未安装,使用 CSS `@keyframes` 替代 |
| 字号调整导致 UI 元素溢出 | 仅调整 2xs/3xs,对现有布局影响极小;逐文件检查确认 |
| 调整手柄加宽后影响拖拽体验 | 保持旧拖拽逻辑不变,仅修改 CSS 类 |
