## 1. 快速开始

### 1.1 首次启动

首次启动 AutoLink 时，系统会自动创建 3 个示例项目，方便您快速体验：

- **示例-H100-100台**：100 台 H100 GPU + 14 存储 + 20 通算（入门示例）
- **示例-H100-128台**：128 台 H100 GPU（4 组 Rail）+ 14 存储 + 20 通算（Rail-Optimized 示例）
- **示例-L20-推理-64**：64 台 L20 推理集群（推理场景示例）

### 1.2 界面布局

AutoLink 采用经典的 IDE 风格布局：

| 区域 | 说明 |
|------|------|
| **顶部菜单栏** | 文件 / 编辑 / 视图 / 项目 / 帮助 |
| **左侧活动栏** | 项目浏览器 / 拓扑设计 / 机柜规划 / 可视化 / 设备库 / 设置 |
| **左侧文件浏览器** | 显示项目列表、输出文件、模板中心 |
| **中间工作区** | 标签页形式展示各功能面板 |
| **右侧面板** | 日志输出 / 属性面板 |
| **底部状态栏** | 当前项目、状态信息 |

### 1.3 创建第一个项目

1. 点击左侧活动栏的「项目浏览器」图标
2. 点击顶部「+」按钮，或选择「从模板创建」
3. 在项目向导中填写：
   - **项目名称**：如 `我的第一个项目`
   - **GPU 服务器型号**：选择 H100 / H800 / L20 等
   - **GPU 服务器数量**：如 100 台
   - **参数网络协议**：RoCE 或 IB
   - **存储/业务/带外网络**：按需开关
4. 点击「下一步」完成设备选型
5. 点击「完成」创建项目

## 2. 项目管理

### 2.1 项目列表

在左侧文件浏览器的「全部项目」区域，可以看到所有项目。每个项目支持以下操作（右键菜单）：

- **设为当前项目**：选中该项目作为操作对象
- **在文件管理器中打开**：打开项目所在目录
- **复制项目**：创建项目副本
- **重命名**：修改项目名称
- **导出为 ZIP**：打包项目为压缩文件
- **转为模板**：将项目保存为可复用模板
- **收藏置顶**：将项目固定在列表顶部
- **删除项目**：移除项目（不可恢复）

### 2.2 项目结构

每个项目的目录结构如下：

```
项目名称/
├── project_config.json    # 项目配置文件（V2.1+ 格式）
├── network_config.ini     # 网络配置文件（V2.0 格式，向后兼容）
├── project.json           # 项目元数据
├── output/                # 输出文件目录
│   ├── connection_table.xlsx
│   ├── rack_table.xlsx
│   └── topology.png
└── topology.json          # 拓扑数据（生成后）
```

### 2.3 项目文件浏览

点击项目名称左侧的展开箭头，可以查看项目内的文件树结构。点击文件可在工作区打开预览：

- **Excel 文件**（.xlsx）：表格形式预览，支持多 Sheet 切换
- **JSON 文件**：语法高亮显示
- **图片文件**（.png/.jpg）：图片预览
- **配置文件**（.ini/.cfg）：文本预览

### 2.4 项目导入导出

- **导入**：支持从 ZIP 文件导入项目
- **导出**：可将单个或多个项目导出为 ZIP
- **批量导出**：在项目列表顶部点击「批量导出」按钮

### 2.5 模板中心

左侧文件浏览器的「模板中心」区域提供场景模板：

- 内置模板：H100 / H800 / L20 等典型场景
- 用户模板：通过「项目转模板」创建的自定义模板
- 支持模板的编辑、导入、导出、删除

## 3. 设备选型

### 3.1 设备选型向导

创建项目时，向导会引导您完成设备选型：

**第一步：基本参数**
- GPU 服务器型号与数量
- 参数网络协议（RoCE / IB）
- 存储服务器配置（全闪 / 混闪）
- 通算服务器数量
- 网络开关（参数网 / 存储网 / 业务网 / 带外管理）

**第二步：设备选型**
- 根据协议自动推荐合适的交换机
- 可手动调整每类设备的型号
- 系统会校验设备参数的合理性

### 3.2 协议联动

AutoLink 会根据参数网络协议自动推荐存储交换机：

| 协议 | 存储交换机推荐 | 说明 |
|------|---------------|------|
| **IB** | NVIDIA Quantum HDR（MQM8700） | IB 存储与参数面共用 Quantum 系列 |
| **RoCE** | 华为 CE6881（48S6CQ） | 专用存储接入交换机，支持 RoCEv2 / FC-NVMe |

### 3.3 设备分类

设备库分为以下类别：

- **GPU 服务器**：H100 / H800 / H200 / B200 / L20 / L40 等
- **存储服务器**：全闪存储 / 混闪存储 / 并行文件系统
- **通算服务器**：通用计算服务器
- **交换机**：
  - 参数面交换机（IB / RoCE）
  - 存储交换机
  - 业务交换机（25G 接入）
  - 带外管理交换机

## 4. 拓扑设计

### 4.1 设计入口

1. 在左侧活动栏点击「拓扑设计」图标
2. 或在菜单栏选择「项目 → 渲染输出」
3. 选择当前项目后，设计面板会显示

### 4.2 拓扑参数

**全模式（自动计算）**
- 系统根据 GPU 服务器数量自动计算交换机数量
- 自动分配下行端口
- 适用于标准场景

**自定义模式**
- 手动指定每台交换机的下行连接数
- 适用于特殊端口规划
- 参数说明：
  - `param_downlink_limit`：参数网每台交换机下行端口数
  - `storage_downlink_limit`：存储网下行端口数
  - `biz_downlink_limit`：业务网下行端口数
  - `oob_downlink_limit`：带外管理下行端口数

### 4.3 生成拓扑

1. 确认参数无误后，点击「生成拓扑」按钮
2. 系统会调用后端 Python 引擎进行计算
3. 生成成功后，工作台状态显示「通过」
4. 如有错误，会在日志面板显示详细信息

### 4.4 拓扑验证

- 生成拓扑后自动进行连通性验证
- 检查所有服务器是否都已接入网络
- 检查端口数量是否匹配
- 验证结果在状态栏显示

## 5. 机柜规划

### 5.1 机柜配置

- **机柜类型**：42U 或 49U
- **功率上限**：默认 6000W，可调整
- **命名前缀**：如「机柜」「Cabinet」等

### 5.2 自动上机

生成拓扑后，系统会自动将设备分配到机柜：

- 按设备类型分组放置
- 考虑机柜功率限制（颜色编码）：
  - 🟢 绿色：功率 < 60%
  - 🟡 黄色：功率 60%-80%
  - 🔴 红色：功率 ≥ 80%
- 自动计算所需机柜数量

### 5.3 机柜视图

在「机柜规划」面板可以：

- 查看每个机柜的设备分布
- 查看机柜功率使用情况
- 导出上机表（Excel 格式）

### 6.1 拓扑可视化

## 7. 输出导出

### 7.1 输出类型

生成拓扑后，可以导出以下文件：

| 输出类型 | 格式 | 说明 |
|---------|------|------|
| 连接关系表 | Excel | 所有网络连接的详细列表（A 端 / Z 端） |
| 上机表 | Excel | 每个机柜的设备分布表 |
| 设备清单 | Excel | 所有设备的汇总清单 |
| 拓扑图 | PNG | 网络拓扑图图片 |

### 7.2 导出方式

- **工作台一键渲染**：在工作台面板点击「一键渲染」，自动生成所有输出
- **菜单导出**：通过「项目 → 导出上机表 / 导出设备清单」单独导出
- **文件预览**：在左侧「输出文件」区域点击文件可直接预览

### 7.3 输出文件管理

- 支持按批次查看输出文件
- 可删除单个输出文件或清空所有输出
- 支持在文件管理器中打开输出目录

## 8. 设备库

### 8.1 浏览设备

在左侧活动栏点击「设备库」图标，可以：

- 按类别筛选设备（GPU 服务器 / 存储服务器 / 交换机等）
- 查看设备详细参数（端口数、速率、功率等）
- 搜索设备（按型号、厂商、标签）

### 8.2 设备库管理

- 内置 109+ 设备，覆盖主流厂商（NVIDIA / 华为 / H3C / 锐捷等）
- 支持自定义设备的添加、编辑、删除
- 支持设备库的导入导出（JSON / Excel 格式）

### 8.3 设备参数说明

**服务器参数**
- `gpu_count`：GPU 数量
- `gpu_model`：GPU 型号
- `power_watts`：功耗（W）
- `u_height`：机柜高度（U）

**交换机参数**
- `port_count`：端口数量
- `port_speed`：端口速率（如 25G / 100G / 200G / 400G）
- `port_type`：端口类型（如 SFP28 / QSFP28 / QSFP56）
- `uplink_port_count`：上联端口数
- `applicable_networks`：适用网络（param / storage / biz / oob）

## 11. 常见问题

### Q1: 生成拓扑失败怎么办？

**A**: 请检查以下几点：
1. 确认已选择项目
2. 确认 GPU 服务器数量 > 0
3. 检查参数网络是否启用
4. 查看日志面板的错误信息
5. 确认设备选型完整（所有启用的网络都有对应交换机）

### Q2: IB 协议下存储交换机推荐了 RoCE 设备？

**A**: 这是 V2.6.0 之前的已知问题，已在 V2.6.0 修复。请确保使用 V2.6.0 及以上版本。IB 协议会推荐 NVIDIA Quantum HDR 交换机，RoCE 协议会推荐华为 CE6881。

### Q3: 项目配置文件 INI 和 JSON 共存时以哪个为准？

**A**: 当 `network_config.ini` 和 `project_config.json` 同时存在时，以 `project_config.json` 为准（JSON 格式更新，支持更多功能）。系统会自动优先读取 JSON 配置。

### Q4: 如何将旧项目（V2.0 INI 格式）升级到新格式？

**A**: 系统会自动检测旧格式项目并提示迁移。迁移后生成 `project_config.json`，原 INI 文件保留作为备份。

### Q5: 导出的 Excel 文件打开是乱码？

**A**: 请使用 Microsoft Excel 或 WPS 打开。如仍有问题，可尝试导出 CSV 格式（注意编码选择 UTF-8）。

### Q6: 切换语言后部分文字仍是中文？

**A**: V2.6.0 已完成全面国际化。如发现遗漏，请通过「帮助 → 检查更新」获取最新版本，或反馈给开发团队。

### Q7: 如何查看软件版本和构建号？

**A**: 点击菜单「帮助 → 关于 AutoLink」，在弹窗底部可以看到版本号和构建号。
