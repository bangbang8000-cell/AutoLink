## 5. 风险与缓解

| 风险 | 概率 | 影响 | 缓解措施 |
|---|---|---|---|
| ICO 生成工具不可用(png-to-ico/ico-endec 依赖问题) | 中 | T5 阻塞 | 备选:用在线工具或 GIMP 手动生成;或用 sharp 生成多尺寸 PNG 后用 PowerShell + System.Drawing 转 ICO |
| 16px 尺寸下 Logo 不可辨(圆圈消失) | 中 | T8 返工 | 预留 0.5d 微调;若不可行则接受 16px 下仅显示 A 轮廓(无节点),32px 起显示节点 |
| R6 模板路径拆分导致已有用户模板丢失 | 低 | 数据丢失 | T3 含迁移脚本:首次启动检测 `resourcesPath/template` 下非内置模板,复制到 `userData/user-templates/`;迁移前备份 |
| macOS 检查更新 quitAndInstall 失败(未签名) | 高 | T14 在 macOS 部分功能不可用 | v2.5 暂不处理,AboutDialog 状态机在 macOS 显示"macOS 请手动下载更新"提示;v2.6 申请证书 |
| preload 暴露 package.json 读取权限被 CSP 拦截 | 低 | T12 阻塞 | main 进程读 package.json 后经 IPC 传渲染进程,避免渲染进程直接读文件 |

## 7. 发版流程

1. 更新 `package.json` version 为 `2.5.0`
2. 更新 `docs/CHANGELOG.md`(如有)
3. 提交:`git commit -m "release: v2.5.0 [skip ci]"`
4. 打 tag:`git tag v2.5.0`
5. 推送:**不带 [skip ci]**,触发 GitHub Actions 三平台构建
   - 按[项目记忆](file:///c:/Users/everg/.trae-cn/memory/projects/-d-MyCoding-AutoLink-AutoLink-v2-0/project_memory.md):tag 推送若 commit 含 [skip ci] 会跳过 tag 触发的 workflow,需手动 `gh workflow run`
   - 建议:release commit 不带 [skip ci],或 push 后手动 `gh workflow run build.yml`
6. CI 生成 Release Notes(`--generate-notes`)
7. 验证 GitHub Releases 三平台产物完整
