## 跨版本通用规范

### 发布流程(每个版本)
1. 更新 `package.json` version + `VERSION` 文件
2. 更新 `CHANGELOG.md`
3. 回归测试:`tsc --noEmit` + `eslint` + `vitest` + `pytest`
4. 提交代码:`git commit -m "feat: vX.Y.Z ..." [skip ci]`
5. 打 tag:`git tag vX.Y.Z`
6. 推送:`git push origin main vX.Y.Z`
7. 触发 CI:`gh workflow run build.yml --ref vX.Y.Z`

### 版本号规范
- 遵循语义化版本(MAJOR.MINOR.PATCH)
- 2.7.X 系列仅递增 MINOR 或 PATCH
- 不使用 alpha/beta 标签(用户偏好)

### 代码规范
- TypeScript 类型导入拆分为 `import type` 语句
- 异步代码使用 async/await,禁止 callback 风格
- 前端组件用 ErrorBoundary 包裹,防止白屏
- 拓扑/机柜数据按项目持久化(topology.json / rack_layout.json)
- 模板资源打包在 resourcesPath/template 目录

### 文档更新
- 每个版本更新 `CHANGELOG.md`
- 重大功能更新 `README.md` 和 `docs/deployment.md`
- PRD 和开发计划同步更新状态标记
